# Android-Debloation-Script

![GitHub last commit (branch)](https://img.shields.io/github/last-commit/kyievdev/Android-Debloation-Script/main) ![GitHub License](https://img.shields.io/github/license/kyievdev/Android-Debloation-Script?style=flat)




A simple way to debloat your Android Device With a Single click.

---

# REQUIREMENTS:

* A Windows PC
* ADB (Android debug bridge) Tools [MUST BE INSTALLED TO RUN]
* USB Debugging And developer options enabled
---
Click [Here](https://dl.google.com/android/repository/platform-tools-latest-windows.zip) to install the required ADB tools.
# WHAT IS DELETED BASED OFF OF THE DEVICES MANUFACTURER:

## SAMSUNG:

* Samsung Goals
* AppCloud
* Application Recommendations
* AR Emoji + Dependencies 
* Auto Doodle
* CameraKit Plugin
* Clipboard Edge
* Cocktailbarservice (Edge bar + Dependencies)
* Smart Switch + Dependencies
* Customization Service
* Live Transcribe & Sound Notifications (Can be reinstalled if you want to)
* Magnifier 
* Google Meet
* Mobile Device Information Provider (smth related to Kindle, nothing important.)
* OneDrive
* Samsung Intelligent Voice Services (most definitely tts) + Dependencies (languages, None of the Device language packs are deleted.)
* Samsung Kids Installer
* SettingsBixby (not useful if you don't have bixby anywhere on the device)
* Sticker Center
* User Guide
* Facebook + Dependencies 
* Voice Access (Voice Access Helps anyone who has difficulty manipulating a touch screen (e.g. due to paralysis, tremor, or temporary injury)
